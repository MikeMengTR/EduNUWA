# 实验评价方案

## 1. TeacherSkill 蒸馏质量评价

评价自动生成或半自动生成的 `TeacherSkill.md` 是否能反映教师讲解方式。

维度：

- 讲解结构覆盖度；
- 类比方式提取准确性；
- 公式解释策略完整性；
- 黑板策略清晰度；
- 可执行性。

## 2. 教师式讲解效果评价

对比：

1. 普通 DeepSeek 回答；
2. DeepSeek + 普通提示词；
3. DeepSeek + TeacherSkill.md。

评价维度：

- 逻辑清晰度；
- 课堂讲解感；
- 易理解程度；
- 教师风格相似度；
- 答案完整度。

## 3. 多模态展示效果评价

对比：

1. 纯文本回答；
2. 文本 + 黑板；
3. 文本 + 黑板 + TTS + Live2D。

评价维度：

- 学习沉浸感；
- 信息组织清晰度；
- 注意力保持；
- 用户满意度。

## 4. 工程指标

- 首次响应时间；
- TTS 生成时间；
- 音频播放稳定性；
- Live2D 口型同步效果；
- 端到端流程是否稳定。
