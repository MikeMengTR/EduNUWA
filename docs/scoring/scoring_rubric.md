# MIND 评分操作手册 (Scoring Rubric v1)

> **用途**：所有人工标注者、LLM Judge prompt 设计者、以及评级算法实现者的**唯一权威依据**。
> 任何对评分的争议必须回到本文档定义。
> **版本控制**：每次修改必须 bump 版本号、记录 changelog；历史 Skill 评分必须标注 `rubric_version` 字段。

---

## 0. 框架总览

MIND 评分由两层指标 + 四类一致性检验聚合而成：

| 层 | 内容 | 用途 |
|---|---|---|
| Layer 1 风格指纹（6 维） | 连续 [0, 1] | 学生侧雷达图 + 匹配 |
| Layer 2 教学策略（5 维） | 枚举 | Agent Prompt 注入 |
| A1 真实性 | 自评 vs 观测一致性 | 防虚假标注 |
| A2 稳定性 | 跨片段一致性 | 防偶发表现 |
| A3 内在一致性 | 6 维与 5 维的语义对齐 | 防自相矛盾 |
| A4 有效性（预留） | 学生学习增益 | Phase 2+ |

A–D 等级由 A1/A2/A3（+ A4）按确定性公式聚合，**LLM 不得直接输出等级**。

## 1. 标注通用规则

### 1.1 流程
1. 至少 **2 位独立标注者** 先各自给所有维度打分（不交流）。
2. 完成后比对，分歧 ≥ 0.20（fingerprint）或不同枚举（pedagogy）的进入复议。
3. 复议时双方陈述证据，争议未解决的提交 **第三人裁判**（导师 / 教育学背景研究生）。
4. 最终输出 **consensus 分数 + 全部证据片段**。

### 1.2 证据要求（**所有打分必须满足**）
- 每个维度的分数必须附 **≥ 2 段转写原文证据**（含时间戳）
- 证据片段长度 30–200 字
- 引用必须能在原始转写中被定位（不允许概括或改写）
- 如果证据少于 2 段，该维度直接标 `INSUFFICIENT_EVIDENCE`，不评分

### 1.3 评分边界
- Fingerprint 分数严格在 [0, 1]，精度到 0.05
- 不允许打 0 或 1（除非极端情况且双人都同意）
- 中间值 0.50 应保留给"确实没有偏向"，而不是"我不确定"

### 1.4 元数据必须记录
| 字段 | 例 |
|---|---|
| 课程主题 | 一阶 RC 电路过渡过程 |
| 学生层级 | 大二电气工程 |
| 班级规模 | 60 人 |
| 录音条件 | 普通教室、单麦克风 |
| 录音时段 | 学期第 8 周 |
| 学科类别 | 工科基础课 |

**严禁跨学科 / 跨层级直接比较分数**——元数据是分层比较的基础。

## 2. Layer 1 · 风格指纹 6 维

### 2.1 Pace（节奏）

**定义**：单位时间内教师传递的信息密度与语速强度的综合表征。
**取值**：0 = 极慢、留白多、信息稀；1 = 极快、信息密集、几乎不停顿。

**评分依据**：
- 词速（中文字符 / 分钟）
- 信息密度（新概念出现频率）
- 停顿与留白比例
- 主题切换频率

**容易误判（false friends）**：
- ❌ "讲得快 = Pace 高"（必须看信息密度，单纯快但内容稀薄是低 Pace）
- ❌ "停顿多 = Pace 低"（要区分"等学生反应"vs"思考自己讲什么"）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.80） | 5 分钟内引入 3 个新概念，每概念解释 < 60 秒就推进；几乎无停顿；"那么这个公式怎么来呢？我们直接看，由欧姆定律..." | 信息密集、推进迅速 |
| 中（0.50） | 5 分钟内 1–2 个新概念，每概念有 30–60 秒铺垫；有意控制节奏；"我们先停一下，这里很重要" | 节奏适中、张弛有度 |
| 低（0.25） | 5 分钟内 1 个概念都没讲完；大量重复、举例、停顿；"我再说一遍啊，这个特别容易错" | 节奏舒缓、重复多 |

---

### 2.2 Detail（详略）

**定义**：教师对单个知识点展开的颗粒度。
**取值**：0 = 一笔带过、抽象骨架；1 = 极尽详细、每步推导、多例验证。

**评分依据**：
- 推导过程是否完整呈现
- 例子数量 / 概念
- 是否复述、是否回顾
- "我不展开，大家自己看书" vs "我们一步步推"

**容易误判**：
- ❌ "话多 = Detail 高"（要看是否在同一个点上展开，而不是发散）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.80） | "这里有 5 个步骤，第一步...第二步...让我们换个角度再看一遍" | 同一点反复展开 |
| 中（0.50） | "推导过程我给大家点关键步骤"，主要节点都讲到但不每步都细 | 选择性详细 |
| 低（0.20） | "结论是这个公式，具体推导大家课后看 PPT" | 跳过细节 |

---

### 2.3 Abstraction（抽象度）

**定义**：教师讲解时**形式化语言 / 具象例子**的比例。
**取值**：0 = 全是具体例子和故事；1 = 全是形式定义和符号操作。

**评分依据**：
- 形式定义、公理、数学符号密度
- 具体例子、故事、类比的密度
- 二者比例（高 Abstraction 意味形式多于具体）

**容易误判**：
- ❌ "用公式 = Abstraction 高"（要看是否解释，纯写公式不解释可能是因为时间紧而非风格抽象）
- ❌ "讲故事 = Abstraction 低"（要看故事是否服务于抽象概念的引入）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.80） | "我们定义如下：设 V(t) 满足 dV/dt + V/RC = 0，则其通解为..." 大量符号、少例子 | 形式优先 |
| 中（0.50） | 形式定义 + 物理直觉解释交替出现；"严格地说...通俗地讲..." | 形式与具象并重 |
| 低（0.20） | "想象一个水池在漏水"、"就像你冲手机一样"，几乎只用比喻 | 具象优先 |

---

### 2.4 Interactivity（互动）

**定义**：教师设计或诱发学生主动参与的程度。
**取值**：0 = 单向讲授；1 = 高频提问、等待、回应。

**评分依据**：
- 真问题（期待回答）的频率
- 反问、设问、修辞问（**不计入**真问题，但要计入 sub-indicator）
- 长停顿次数（≥ 3 秒，明显为等学生）
- "谁来说说"、"举个手"、"你觉得呢"等明确招呼

**容易误判**：
- ❌ "提问多 = Interactivity 高"（修辞问"对吧？"不算真互动）
- ❌ "大班课天然低互动"（用元数据中的班级规模做基线调整，不能因此压分）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.80） | 每 5 分钟 ≥ 2 次真问题 + 等待 + 学生回应 + 反馈；"你说说看？...对，但还有一种情况..." | 双向频繁 |
| 中（0.50） | 偶尔提问，多数学生回答后教师简单确认即推进 | 有互动但不深入 |
| 低（0.15） | 几乎全程独白；偶有"对吧？"作为衔接词，无等待 | 单向讲授 |

---

### 2.5 Humor（幽默）

**定义**：教师有意制造轻松、引发笑声或愉悦的程度。
**取值**：0 = 严肃枯燥；1 = 频繁玩笑、夸张、自嘲。

**评分依据**：
- 听众笑声（音频检测可作辅助）
- 自嘲、调侃、夸张语气
- 与内容无关但有趣的小故事
- 双关、谐音

**容易误判**：
- ❌ "讲故事 = Humor 高"（要看是否有意制造笑点，严肃讲历史故事不算幽默）
- ❌ "音频里没有笑声 = Humor 低"（学生录音少有清晰笑声；以语言特征为主）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.75） | "我们老师当年讲这块的时候我也听不懂，所以现在我说快了你们就打断我啊"、明显的反话、夸张 | 频繁制造轻松 |
| 中（0.40） | 偶尔的轻松话语、点到为止的小段子 | 适度调剂 |
| 低（0.15） | 全程严肃语气，无情绪起伏 | 严肃风格 |

---

### 2.6 Rigor（严谨）

**定义**：教师对概念准确性、定义边界、推导完整性的把控程度。
**取值**：0 = 模糊、近似、随手讲；1 = 形式严密、定义清晰、错误必纠。

**评分依据**：
- 形式定义出现频率
- 错误自我纠正频率
- 假设、前提的明示
- 模糊修饰语（"差不多"、"大概"）的反向频率

**容易误判**：
- ❌ "用术语 = Rigor 高"（要看是否区分定义和近似）
- ❌ "说话快 = 不严谨"（节奏和严谨度正交）

| 锚点 | 分数 | 范例证据 |
|---|---|---|
| 高（0.80） | "严格说，这里要求 f 在区间上连续可微，而不仅仅是连续。我们后面会用到这个区别" | 主动区分边界 |
| 中（0.50） | 主要概念准确，细节偶有"大致就是这样"的简化 | 整体严谨、局部放松 |
| 低（0.20） | "差不多就这意思"、"大概就是这样"频繁出现；无定义边界 | 直觉为主、不严格 |

## 3. Layer 2 · 教学策略 5 维（枚举）

### 3.1 Concept Entry（概念入口）

**定义**：教师引入一个新概念时**首先呈现什么**。

| 枚举值 | 含义 | 判定依据 |
|---|---|---|
| `top_down_definition` | 先给形式定义再展开 | 新概念出现后前 90 秒内首先是定义 |
| `bottom_up_example` | 先给例子再抽象 | 前 90 秒先是具体场景 / 数据 |
| `problem_driven` | 先抛问题再解答 | 前 90 秒先是问句或挑战 |
| `analogy_first` | 先给类比再形式化 | 前 90 秒先是"像 X 一样" |

**判定规则**：观察 ≥ 5 个新概念引入实例，多数投票（≥ 3 票）。若分布过散（无优势项），标 `mixed`。

---

### 3.2 Intuition Building（直觉构建）

**定义**：教师在抽象与具象之间架桥的偏好方式。

| 枚举值 | 含义 |
|---|---|
| `concrete_first` | 大量用日常例子建立直觉 |
| `analogy_driven` | 用跨领域类比（"水流 = 电流"） |
| `visual_first` | 优先画图、用可视化 |
| `formal_first` | 直接从形式定义出发，不刻意建直觉 |
| `historical` | 用历史发展脉络引入 |

**判定规则**：观察 ≥ 5 个抽象概念的处理方式，多数投票。

---

### 3.3 Analogy Density（类比密度）

**定义**：单位时间内出现的跨域类比频率。

| 枚举值 | 阈值 |
|---|---|
| `sparse` | < 1 个 / 10 min |
| `moderate` | 1–3 个 / 10 min |
| `dense` | ≥ 3 个 / 10 min |

**判定规则**：自动 + 人工双轨。LLM 标记候选类比，人工确认是否为"跨域类比"（同领域里的换种说法不算）。

---

### 3.4 Blackboard Strategy（板书策略）

**定义**：教师使用板书的整体节奏。

| 枚举值 | 含义 | 判定依据 |
|---|---|---|
| `outline_driven` | 先写章节大纲，再填内容 | 课程前 10 分钟已写出大纲 |
| `build_up` | 按讲解节奏逐步累积 | 板书随时间线性增长 |
| `demo_driven` | 单一推导 / 例题占满板面 | 一次板书集中于一个对象 |
| `minimal` | 几乎不用板书，主要靠 PPT / 口述 | 板书使用 < 课时 20% |
| `mixed` | 混合多种策略 | 上述都不占主导 |

**数据要求**：需要板书照片或视频；只有转写无法判定。无数据则标 `INSUFFICIENT_EVIDENCE`。

---

### 3.5 Misconception Alert（误区预警）

**定义**：教师如何处理学生常见错误。

| 枚举值 | 含义 |
|---|---|
| `preventive` | 在错误发生前主动预警："这里很容易错的地方是..." |
| `reactive` | 在学生回答 / 提问后纠正 |
| `implicit` | 不显式提及误区，只展示正确做法 |
| `interactive` | 有意诱发错误（让学生先试错） |

**判定规则**：统计转写中"容易错"、"千万不要"、"看似..实际"等模式的出现位置（在错误发生前还是后）。

## 4. 一致性检验定义

### 4.1 A1 真实性（Authenticity）

```python
A1_fp  = 1 - mean(|self_score[i] - observed_score[i]|)  for i in 6 fingerprint dims
A1_ped = mean( self_enum[j] == observed_enum[j] )        for j in 5 pedagogy dims
A1     = 0.6 * A1_fp + 0.4 * A1_ped
```

**异常子类型**：
- **失谐型**：偏差均值接近 0、方差大 → 标记 `self_misperception`，不扣大分
- **造假型**：偏差均值显著偏向某方向（如普遍夸大 Rigor） → 触发 `suspected_inflation` 红线

### 4.2 A2 稳定性（Stability）

```python
# 将语料按 session 切成 N ≥ 3 段
A2_fp  = mean Pearson r over 6 dims across all segment pairs
A2_ped = Fleiss' kappa over 5 dims across all segments
A2     = 0.6 * A2_fp + 0.4 * A2_ped
```

**数据要求**：每段必须 ≥ 30 分钟有效内容；否则标 `INSUFFICIENT_EVIDENCE`，不评 A2。

### 4.3 A3 内在一致性（Coherence）

**MVP 规则表**（v1，需根据数据迭代）：

| 条件 A | 期望的 B |
|---|---|
| `Rigor > 0.70` | `Concept Entry` 偏 `top_down` 或 `formal_first` |
| `Interactivity > 0.70` | `Misconception Alert` 含 `reactive` 或 `interactive` |
| `Humor > 0.60` | `Concept Entry` 不偏 `top_down_definition`（否则可能矛盾） |
| `Abstraction > 0.70` | `Intuition Building` 含 `formal_first` |
| `Analogy Density = dense` | `Intuition Building` 含 `analogy_driven` 或 `concrete_first` |

```python
A3 = matched_rules / total_applicable_rules
```

**注意**：规则违反不是错，可能反映教师的独特风格。A3 < 0.5 时**触发人工复核**，不直接扣分。

### 4.4 等级聚合

```python
quality_score = 0.40 * A1 + 0.30 * A2 + 0.30 * A3
                # A4 暂留 None；引入后重新分配权重

# 红线
if suspected_inflation_detected:        max_grade = "C-"
if A2 < 0.50:                            max_grade = "C+"
if any dim 证据 < 10 min:                grade     = "UNGRADED"

# 映射 (7 级简化版本)
score >= 0.90 → A+
score >= 0.80 → A
score >= 0.70 → B+
score >= 0.60 → B
score >= 0.50 → C+
score >= 0.35 → C
score <  0.35 → D
```

## 5. 分歧解决协议

| 情形 | 协议 |
|---|---|
| 两人 fingerprint 分歧 < 0.10 | 直接取平均 |
| 两人 fingerprint 分歧 0.10–0.20 | 任一方写 50 字理由，再决定 |
| 两人 fingerprint 分歧 ≥ 0.20 | 必须复议；复议未果 → 第三人裁判 |
| 两人 pedagogy 不同枚举 | 直接复议 |
| 复议后仍无共识 | 标 `DISPUTED`，进入研究案例集，不入校准库 |

## 6. 校准库管理

- 所有人工标注样本入 `data/teacher_skill/scoring/gold_samples/`
- 每个样本独立 JSON：原始转写片段 + 两人标注 + consensus + 复议日志
- 校准库每加入 ≥ 5 个新样本要触发：
  1. LLM Judge 在历史样本上重测，验证 MAE 未漂移
  2. 与人工历史 consensus 的相关性 ≥ 0.7 阈值检查
- 校准库版本与 prompt 版本一一绑定
